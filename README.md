# MEDICARE PLUS — Premium Healthcare Clinic Website

A complete, premium, responsive healthcare clinic & appointment platform built **100% frontend**.
No backend, no database, no API, no server-side authentication.

---

## 🚀 Getting Started

1. Open the `medicare-plus` folder in **VS Code**.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` → **Open with Live Server**.
4. The site opens at `http://127.0.0.1:5500`.

> You can also open `index.html` directly in a browser — everything works without a server.
